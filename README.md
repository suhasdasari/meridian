# Meridian

A live world news desk. Headlines as published. No editorial ranking.

The lead story is the cluster with the most independent outlets in the current cycle, weighted only by recency and geographic spread of coverage. The wire is chronological. Default edition is World; any desk can switch to a country.

Sources include public broadcasters, newspaper RSS, Google News editions, GDELT, ReliefWeb, UN News, WHO, and Wikipedia current events.

## Run

```bash
npm install
npm run dev
```

Requires Node 22.
